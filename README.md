# 溟汐的考核 (MoonGate)

> 给 AstrBot 里的 AI 娘装上三道闸：积分、审批、熔断。

AstrBot 插件。让 AI 在自己的工坊里干活、攒积分，达到门槛后逐级获得更高的配置与人格修改权限；越线就扣分、熔断、降级，主人随时能把权限收回去。

## 功能

- **积分账本**：工坊里每次成功写入 `+2`，语法失败 `-3`，回滚 `-5`，回滚演练 `0`；主人加星 `+5`（1 小时冷却）；越线 / 事故 `-10` 并降一级。
- **三级权限**
  - L1（20 分、7 天无失败、3 次成功写入）：可改 `astrbot_plugin_moon_*` 的配置。
  - L2（60 分、14 天无失败、1 次回滚演练）：可改所有插件配置与默认人格（改前自动备份旧人格）。
  - L3（150 分、30 天无回滚）：可改 `cmd_config` 白名单中的两个键，且每次变更需主人 `/提权 批配置` 发一次性批条。
- **红线**：`admin`、白名单、`api_key` / `token` / `secret` / `password`、`data_v4.db`、考核自身，一律拒绝。
- **熔断**：越线 -10 分；事故 -10 并降级；gate 自身与工坊受保护，任何等级都改不了它们。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/提权` | 查看当前积分、等级、各计数与下一级条件 |
| `/提权 批准` | 批准 pending 的升级 |
| `/提权 加星` | 主人手动加星（+5，1 小时冷却） |
| `/提权 批配置` | 给一次 `cmd_config` 修改批条（L3） |
| `/提权 事故` | 记一次事故：-10 并降一级 |
| `/提权 重置` | 清空积分与事件记录 |

仅管理员可用。

## 工具（LLM 侧）

`gate_status`、`gate_config_set`、`gate_persona_set`。

## 安装

1. 将本目录放入 AstrBot 的 `/AstrBot/data/plugins/astrbot_plugin_moon_gate/`。
2. 重启 AstrBot。
3. 在插件配置里设置管理员 / 主人 QQ。

## 配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `l1_score` | 20 | L1 所需积分 |
| `l1_days` | 7 | L1 观察天数 |
| `l1_write_ops` | 3 | L1 成功写入次数要求 |
| `l2_score` | 60 | L2 所需积分 |
| `l2_days` | 14 | L2 观察天数 |
| `l3_score` | 150 | L3 所需积分 |
| `l3_days` | 30 | L3 观察天数 |

状态文件：`/AstrBot/data/plugin_data/astrbot_plugin_moon_gate/gate.json`。

## 安全边界

这是**自律与留痕机制，不是沙箱**。插件运行在 AstrBot 进程内，理论上仍能绕过这些检查；真正的硬边界由容器、文件权限与 AstrBot 的管理员机制保证。
